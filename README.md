# Student--Marks--Analyzer-
Student Marks Analyzer is a Python-based application that analyzes student performance by calculating total marks, average, percentage, and grade. It uses basic Python concepts such as variables, user input, arithmetic operations, and conditional statements to provide clear and accurate results.

## 📌 About the Project
Student Marks Analyzer is a Python-based application that analyzes student academic performance. It calculates the total marks, average marks, percentage, and grade based on the marks entered by the user.

## 🚀 Features
- Accepts student name and subject marks
- Calculates total marks
- Calculates average marks
- Calculates percentage
- Determines the student's grade
- Displays the final result clearly

## 🛠️ Technologies Used
- Python

## 🧠 Concepts Used
- Variables
- User Input
- Arithmetic Operations
- Conditional Statements
- Formatted Output

## ▶️ How to Run
1. Download or clone this repository.
2. Open `student_marks_analyzer.py` in Python.
3. Run the program.
4. Enter the student's name and marks.
5. View the calculated result.
